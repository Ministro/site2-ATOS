# Máquina de Garra — arquivos separados

Arquivos:
- `index.html`: estrutura da página e carregamento das bibliotecas.
- `style.css`: todos os estilos visuais.
- `assets.js`: modelos/recursos incorporados em Base64.
- `game.js`: lógica principal, física, controles e renderização.

Abra `index.html` em um servidor local. Exemplo com Python:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
