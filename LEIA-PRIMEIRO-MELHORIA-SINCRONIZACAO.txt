MELHORIA DA SINCRONIZAÇÃO DE PAGAMENTOS
=======================================

1. No Supabase, abra SQL Editor > New query.
2. Cole e execute todo o arquivo:
   supabase-melhoria-sincronizacao.sql
3. Publique esta pasta/ZIP na Vercel e faça Redeploy.
4. Não altere a URL já cadastrada no EasyCron.
5. Aguarde uma execução ou abra a URL manualmente para testar.

O QUE MUDOU
-----------
- Guarda o horário da última sincronização concluída.
- Usa uma margem de segurança de 10 minutos para não perder baixas atrasadas.
- Consulta apenas as datas necessárias, normalmente somente o dia atual.
- Verifica no Supabase quais faturas já foram processadas antes de buscar cada cliente no IXC.
- Registra todas as execuções em game_sync_logs.
- Mantém fatura_id único, portanto uma fatura nunca gera créditos duas vezes.

COMO CONFERIR OS LOGS
---------------------
No Supabase, abra Table Editor > game_sync_logs.
Os registros mostram horário, quantidade encontrada, creditada, duplicada e erros.

A tabela game_sync_estado guarda o último horário concluído e não deve ser editada manualmente.
