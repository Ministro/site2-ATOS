ATOS TELECOM — PRÊMIOS COM TOKEN ÚNICO

1. No Supabase, abra SQL Editor > New Query.
2. Execute todo o arquivo supabase-premios-tokens.sql.
3. Publique este projeto na Vercel e faça Redeploy.

Funcionamento:
- Cada unidade cadastrada gera um token único.
- Quando o cliente ganha, uma unidade sai do estoque e o token fica reservado.
- A tela mostra prêmio, orientação para tirar print/foto e o token.
- No painel Admin > Prêmios, digite o token para confirmar a retirada.
- Depois da confirmação, o token fica como resgatado e não pode ser usado novamente.
- Um print enviado para outra pessoa não permite retirada duplicada.
