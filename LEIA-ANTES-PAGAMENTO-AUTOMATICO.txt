PAGAMENTO IXC -> CRÉDITOS DO MINI GAME

1. No Supabase, abra SQL Editor.
2. Execute o arquivo supabase-game-setup.sql desta versão (pode executar novamente).
3. Publique o conteúdo do ZIP na Vercel e faça Redeploy.
4. Mantenha as variáveis já existentes:
   IXC_URL, IXC_USER, IXC_PASS, SUPABASE_URL, SUPABASE_SECRET_KEY.

Funcionamento:
- O CPF localiza o cliente e a fatura no IXC.
- A tela guarda o ID exato da fatura mostrada.
- A cada 5 segundos, o site verifica somente essa fatura.
- Quando o status vira R (Recebido), a API recupera CPF/nome no IXC.
- Cada R$ 50,00 pagos gera 1 crédito.
- A fatura fica registrada em game_pagamentos.
- A mesma fatura não pode gerar créditos novamente.
