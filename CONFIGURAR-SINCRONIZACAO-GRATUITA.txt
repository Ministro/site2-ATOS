SINCRONIZAÇÃO AUTOMÁTICA GRATUITA — IXC → SUPABASE

Esta versão não depende de o cliente deixar o site aberto.
Quando uma fatura receber baixa no IXC, uma chamada automática identifica o pagamento e envia os créditos ao Supabase.

1) NA VERCEL
Abra o projeto > Settings > Environment Variables e crie:

CRON_SECRET

Use uma senha grande e aleatória, por exemplo com pelo menos 20 caracteres.
Depois faça um novo redeploy.

2) TESTE MANUAL
Abra no navegador, trocando os dados:

https://SEU-DOMINIO.vercel.app/api/sincronizar-pagamentos?secret=SUA_SENHA

A resposta deve conter "ok": true.

3) AGENDADOR GRATUITO
Crie uma conta em um serviço gratuito de cron HTTP, como cron-job.org.
Crie uma tarefa para chamar a URL abaixo a cada 5 minutos:

https://SEU-DOMINIO.vercel.app/api/sincronizar-pagamentos?secret=SUA_SENHA

Método: GET
Intervalo: 5 minutos

4) COMO FUNCIONA
- Pagamento pelo site: o site ainda mostra FATURA PAGA COM SUCESSO.
- Pagamento por WhatsApp, presencial ou baixa manual no IXC: o agendador detecta sem o site estar aberto.
- R$ 149,99 gera 2 créditos; R$ 150,00 gera 3 créditos.
- A mesma fatura nunca gera créditos duas vezes, porque fatura_id é único.
- A sincronização procura pagamentos/baixas do dia atual no horário de Rondônia.

5) SUPABASE
O SQL game_adicionar_creditos já precisa estar instalado, usando o arquivo supabase-game-setup.sql.
